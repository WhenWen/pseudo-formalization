== ERROR ==
title: Resolvent absolute continuity is overstated from mu-a.e. to every initial condition
type / severity: false_claim / fatal
description: The lemma asserts that the normalized resolvent is absolutely continuous with respect to mu for every initial condition x in E. According to the referees, Bounebache--Zambotti Proposition 2.5 only proves such absolute continuity for mu-almost every x, or equivalently constructs an absolutely continuous kernel that agrees with the actual resolvent only for mu-a.e. x. No argument is given to upgrade this a.e. statement to the pointwise statement needed here. Thus the lemma is false or at least unproved as stated, and it removes the key input needed to handle invariant measures singular with respect to mu.
